# MICEPLANNER 문서

이 디렉터리는 제품 요구사항과 기술 결정을 함께 관리한다. 기능을 구현하거나 정책을 바꾸기 전에 관련 문서의 확정 사항과 열린 결정을 확인한다.

| 문서 | 목적 |
| --- | --- |
| [기능 명세서](functional-specification.md) | 사용자 역할별 기능 범위, 권한, 수용 기준, 단계별 출시 범위 |
| [기술 결정 ADR](adr/0001-technical-decisions.md) | 기술 스택, 아키텍처 경계, 보안 및 운영 결정 |
| [디자인 시스템](design-system.md) | 색·타이포그래피·간격 토큰 정의와 컴포넌트 규격 |

## 문서 상태

- 기준일: 2026-10-20
- 기능 명세서: 초안. 2026-10-20 행사 플래너 명세(행사 멤버 권한, Program·Task·Subtask 계층, 기업 7화면, 클라이언트 Program 일정 노출)를 반영했다. 구현 전 세부 상태값, 필드, API 계약을 보완한다.
- ADR 0001: 기술 방향의 결정본을 구조화한 기록. 열린 결정은 해당 재검토 시점 전까지 구현의 전제로 사용하지 않는다.
